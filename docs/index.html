FAQ

Does it publish automatically?

No. Draft approval is mandatory before any connector can publish.

Can I use a local model?

Yes. Ollama is the default and cloud-compatible providers are optional.

Can reports become PDFs?

Export the self-contained HTML, open it in any browser, and use Print → Save as PDF.

Is it a hosted service?

The MIT project runs locally. A managed offering is only a future business idea, not a current service.
